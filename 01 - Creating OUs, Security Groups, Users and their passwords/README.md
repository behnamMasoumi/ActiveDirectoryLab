# Marketing Team Organization

Created a dedicated **Marketing OU (Organizational Unit)** within the existing OU structure to keep Active Directory organized and make users easier to locate.

- Created two Marketing users: **Jessica** and **Megan**.
- Created a **Marketing Security Group** and added both users.
- Using a security group allows permissions and policies to be assigned to the group rather than individually to each user, making administration more organized and scalable.
